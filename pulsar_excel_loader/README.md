# Пакетная загрузка в «Пульсар теплосчетчик стандартный» · CLI 1.0.1

Для обычной работы используйте графическое приложение `../PulsarLoader`. Эта версия сохранена для запуска из PowerShell и диагностики. Готовых планов и данных объекта в комплекте нет.

## Быстрый запуск — PowerShell

Установите окружение один раз в папке `pulsar_excel_loader`:

```powershell
winget install --id Python.Python.3.12 --exact --scope user --accept-package-agreements --accept-source-agreements
$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [Environment]::GetEnvironmentVariable("Path", "User")
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Создайте план из своей книги, без сетевых запросов:

```powershell
.\run.cmd plan "C:\Данные\Объект.xlsx" --out plan.json
```

Ниже **выдуманный** номер прибора. Замените его номером из своей книги.

```powershell
.\run.cmd read plan.json --meter 12345678 --report-dir reports\pilot-read
.\run.cmd apply plan.json --meter 12345678 --report-dir reports\pilot-write
```

После успешной аппаратной проверки одного прибора можно записать всю готовую партию:

```powershell
.\run.cmd apply plan.json --all --report-dir reports\batch-write
```

`read` выполняет только чтение; `apply` записывает четыре поля. Для каждого повторного запуска задавайте новую папку отчёта. Номер версии: `.\run.cmd --version`.

## Формат и операции

CLI читает лист `Лист1` исходного формата: C — номер теплосчётчика, I — IPv4-адрес, **K — TCP-порт**, M — номер для показаний N/O. N — ХВС в м³ для входа 1, O — ГВС в м³ для входа 2. Показания сопоставляются по C↔M, а не по строкам. Веса обоих входов — 0.01 м³/имп.

Сначала проверяется заводской номер и читаются четыре текущих значения. Запись идёт в порядке: `P00C0.F32`, `P00C3.F32`, `K9.F32`, `K10.F32`. Каждое изменение проверяется чтением. При ошибке оставшиеся поля текущего прибора не записываются; отчёт показывает частичный результат. Потерянное подтверждение проверяется переподключением и чтением, без автоматического повторения записи.

Явная замена ошибочного номера в C и M задаётся опцией `--serial-correction СТАРЫЙ=НОВЫЙ`. Excel остаётся неизменным. Неверные значения не заменяются нулями; корректные числовые нули сохраняются.

Отчёт: `results.csv`, `results.json`, `events.jsonl` и копия плана. Время ожидания запроса по умолчанию 5 секунд, настройка — `--timeout 10`. В `fixtures` и тестах используются только синтетические данные. Полное чтение и запись на реальном приборе требуют проверки оператором.
