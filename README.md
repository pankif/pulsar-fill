# pulsar-fill

Приложение для загрузки начальных показаний и весов импульса в **«Пульсар теплосчетчик стандартный»** через TCP/IP из Excel.

## Быстрый запуск — Windows 10/11 x64

Скачайте [переносимый комплект](releases/PulsarLoader-Windows-x64-v1.1.0.zip), распакуйте весь ZIP и откройте `PulsarLoader.exe`. Python и библиотеки уже внутри.

Либо клонируйте репозиторий в PowerShell:

```powershell
git clone git@github.com:pankif/pulsar-fill.git
cd pulsar-fill
.\PulsarLoader\PulsarLoader.exe
```

Обновить существующую копию:

```powershell
git pull --ff-only
.\PulsarLoader\PulsarLoader.exe
```

В окне выберите Excel и лист, посмотрите ошибки и отметьте приборы. Сначала прочитайте один прибор, затем проверьте список и подтвердите запись. IP берётся из I, TCP-порт из **K**, ХВС из N записывается во вход 1, ГВС из O — во вход 2. Веса обоих входов по умолчанию **0.01 м³/имп**. Подробности: [инструкция приложения](PulsarLoader/README.md).

Исходные Excel, планы, журналы и данные объекта в репозиторий и архивы не включены. В тестах и примерах используются выдуманные номера, адрес `127.0.0.1` и синтетические показания. Не добавляйте рабочие данные в Git; сохраняйте их в игнорируемых каталогах `local/`, `inputs/`, `plans/` или `reports/`.

## Проверка исходников

Для разработки нужен Python 3.10+ с Tkinter; тесты интерфейса запускаются в графическом сеансе. Для обычного запуска Windows-приложения установка Python не требуется.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r PulsarLoader\app\requirements.txt
cd PulsarLoader\app
..\..\.venv\Scripts\python.exe -m unittest discover -v
```

Тесты интерфейса: задайте `PULSAR_GUI_TEST=1`. Необязательная локальная книга для дополнительной проверки задаётся через `PULSAR_TEST_XLSX`; без неё соответствующий тест пропускается. Сетевой обмен в тестах заменён имитатором.

Локальные проверки не подтверждают работу конкретной прошивки и запись на физический прибор. Запуск Windows EXE и операции на реальном счётчике проверяются отдельно оператором. Результаты проверки комплекта: [verification.json](PulsarLoader/verification.json).
