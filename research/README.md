# Материалы статического исследования

Здесь сохранены разбор IL библиотек TestAll, список типов, описание модели 420, извлечённый текст руководства и вспомогательный разборщик `disassemble.py`. Это источники первоначального исследования; текущее поведение клиента описано в `../PulsarLoader/README.md`.

Разборщик — вспомогательный скрипт исходной сессии с путями `work/unpacked/data/{app}` и зависимостями `dnfile`, `dncil`. Он не участвует в работе приложения. Установщик TestAll, извлечённые исполняемые библиотеки и временные окружения не включены. Происхождение и SHA-256 исходных материалов приведены в `../docs/testall-pulsar-standard-analysis.md`.

Книги Excel, планы подключения, журналы опроса и данные объекта здесь отсутствуют.
