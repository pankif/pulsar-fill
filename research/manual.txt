===== СТРАНИЦА 3 =====
 
 
Назначение. 
ПО TestAll используется для настройки и проведения пуско-наладочных работ с 
приборами торговой марки «Пульсар». 
На нашем сайте pulsarm.ru представлено ПО TestAll в двух версиях: 
1. TestAll только с нашими приборами торговой марки «Пульсар». 
2. TestAll для пользователей ПО «ИАСКУЭ», содержащий в себе приборы нашей 
торговой марки и приборы сторонних производителей, которые поддерживаются в нашем 
ПО верхнего уровня. 
1. Типы соединений. 
TestAll поддерживает следующие типы соединений (рис. 1): 
RS-232 . 
TCP Client/Server. 
GSM-CSD. 
UDP Client. 
TCP Server с ID.

В графе «Общие параметры» указываются: 
Время ожидания (время, за которое программа ожидает ответ от прибора).

Время ожидания и пауза перед запросом указываются в миллисекундах.

1.2. TCP Client/TCP Server. 
 
TCP Client/Server выбирается для приборов, которые работают в режиме ТСP Client/Server (если 
прибор в режиме Client, то в TestAll выбирается тип Server (рис. 4 и рис. 5), если Server, то 
выбирается тип соединения Client (рис. 6 и рис. 7)). 
В типе соединения TCP Server вводится только tcp-порт, в режиме TCP Client – используемый ip-
адрес и tcp-порт.

1.4. UDP Client. 
 
Если модем или преобразователь работают в режиме UDP Server, то тип соединения выбирается 
UDP Client, вводятся ip адрес и tcp-порт. Настройки аналогичны режиму TCP, отличие лишь в 
самом соединении (рис. 9).

Рисунок 9. 
 
1.5. TCP Server с ID. 
 
Если модем в режиме TCP Server ID, то используем такой же тип соединения. В графе 
порт вводим tcp-порт, в графе ID - ID модема, подключение которого ожидается (рис. 10). 
В TCP сервер ID задействован один порт, но у каждого прибора дополнительно 
настраивается ID, по которому происходит опрос этого прибора с порта, т.е. не нужно 
создавать требуемое количество соединений TCP сервера 
Сначала в TestAll для требуемого прибора задаётся ID латинскими буквами или цифрами, 
после чего сохраняете изменения для выбранного параметра нажатием на кнопку 
"Запись".

2. Подключение приборов. 
 
При подключении приборов торговой марки Пульсар нужно в графе «Сетевой адрес» 
ввести заводской номер прибора, который по умолчанию является сетевым адресом (рис. 
11), выбрать любой прибор из списка наших приборов (рис. 12), и нажать появившуюся 
кнопку «Тип» для определения драйвера, с которым работает данный прибор (рис. 13). 
Если на линии находится один прибор, то подключиться к нему можно по 
широковещательному адресу «1» , выбрав любой прибор нашего производства, и нажав на 
кнопку «Адрес» (рис. 14 и рис. 15). 
Для подключения приборов сторонних изготовителей нужно выбрать тип прибора и 
ввести его сетевой адрес (рис. 16).

3.1. Значения показаний ПО TestAll («качества»). 
 
20000 - нет данных (например, в приборе отсутствует какой-то тип архивов: прибор 
модификации ЭКО, у которого есть только месячные архивы, а с него пытаются запросить 
суточные). 
192 - ошибок нет (чтение данных происходит, отображаются показания, которые записаны 
в приборе). 
12 - прибор не отвечает, либо ответы искажены (физическое подключение: отсутствует 
питание на интерфейс, перепутаны местами провода, и т. п.). 
4 - параметр не поддерживается драйвером (драйвер прибора отсутствует).
