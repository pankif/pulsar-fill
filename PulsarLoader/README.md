# Пульсар — загрузка из Excel · 1.1.0

**Быстрый запуск на Windows 10/11 x64:** распакуйте весь ZIP → откройте `PulsarLoader.exe` → нажмите **«Открыть Excel…»**. Python устанавливать и команды вводить не нужно. Папки `app` и `runtime` должны оставаться рядом с EXE.

Приложение настраивает модель **«Пульсар теплосчетчик стандартный»** через TCP/IP. Вы выбираете файл и лист; адреса, порты и начальные показания загружаются из него. Подготовленный JSON для работы не требуется.

## Как пользоваться

1. Откройте `.xlsx`. При необходимости выберите лист в списке. Формат колонок должен соответствовать исходной таблице.
2. Посмотрите вкладку **«Проверка Excel»**: ошибочные строки исключены из обработки. Исправьте их в Excel и нажмите **«Проверить заново»** либо используйте **«Исправления номеров…»** для явной замены номера сразу в C и M. Исходный файл приложение не меняет.
3. Проверьте веса импульса обоих входов. По умолчанию стоят **0.01 м³/имп**; допускается десятичная запятая. Эти значения записываются вместе с показаниями.
4. Отметьте приборы в первой колонке. Есть поиск по номеру, квартире и адресу, **«Выбрать видимые»** и **«Снять выбор»**. Поиск скрывает строки; ранее выбранные скрытые приборы остаются выбранными, их учитывает общий счётчик.
5. Для первой проверки отметьте **один прибор** и нажмите **«Прочитать выбранные»**. Эта кнопка выполняет только чтение. В таблице появятся ХВС/ГВС прибора; при выборе строки снизу доступны веса и значения до/после.
6. Для настройки нажмите **«Записать выбранные…»**. В отдельном окне показаны все выбранные приборы, IP/порты и четыре значения. Кнопка **«Записать эти приборы»** начинает запись.
7. Дождитесь завершения. **«Стоп после текущего»** завершает текущий прибор с проверкой и останавливается перед следующим. **«Открыть отчёт»** показывает папку результата в Проводнике.

Новая загрузка файла или повторная проверка сбрасывает выбор и результаты в таблице; сохранённые отчёты остаются. Если редактировали Excel после загрузки, нажмите «Проверить заново», чтобы обновить данные в приложении.

## Формат Excel

| Колонка | Содержимое |
|---|---|
| A / B | Секция / квартира |
| C | Номер теплосчётчика, он же адрес устройства, до 8 цифр |
| I | IPv4-адрес TCP-подключения |
| **K** | **TCP-порт; J для подключения не используется** |
| M | Номер теплосчётчика, к которому относятся значения N/O |
| N | ХВС, м³ → импульсный вход 1 |
| O | ГВС, м³ → импульсный вход 2 |

Показания сопоставляются по номерам C↔M, а не по порядку строк. Заголовки первой строки проверяются по исходному формату (A–E, G–J, N/O). Названия файла и листа произвольные. Все строки выбранного листа проверяются заново; число приборов не задано в программе.

Показания и порт должны быть исходными числами. Формулы в N/O и ошибки Excel исключаются; корректные нулевые показания сохраняются. Неправильные адреса, недопустимые номера и дубли не выбираются автоматически. Листы обрабатываются по одному; выберите нужный лист, если он имеет такой же формат.

Исправления номеров задаются явно в окне, например `123456788=12345678` (выдуманный пример). Исходные книги и данные объекта в комплект не входят.

## Что происходит при записи

Приложение подключается последовательно, проверяет заводской номер и читает все четыре текущих значения. Затем задаёт:

1. Вес импульса входа 1 (`P00C0.F32`).
2. Вес импульса входа 2 (`P00C3.F32`).
3. Начальное показание входа 1 из N (`K9.F32`).
4. Начальное показание входа 2 из O (`K10.F32`).

Каждое изменённое поле проверяется повторным чтением; совпадающие значения не переписываются. При ошибке оставшиеся поля этого прибора не записываются, обработка переходит к следующему. Это четыре отдельные операции: возможен частичный результат, который отражается в отчёте. При потерянном подтверждении приложение переподключается и проверяет значение чтением, без автоматического повторения записи.

Прибор хранит значения в Float32: например, 0.01 может читаться как 0.0099999998. Проверка сравнивает значение с тем же представлением Float32; в подробном отчёте сохраняется фактическая точность.

Таймаут в окне относится к одному запросу. Завершение текущего прибора после остановки может занять несколько таймаутов. Не запускайте несколько экземпляров для записи одних и тех же приборов одновременно.

## Отчёты и ошибки запуска

По умолчанию отчёты создаются в `Documents\PulsarLoader\Reports` внутри профиля пользователя. Другую папку можно выбрать кнопкой **«Папка отчётов…»** на текущий сеанс. Для каждого запуска создаётся отдельная папка:

- `results.csv` — таблица для Excel, включая результат каждого поля и значения до/после;
- `results.json` — подробные результаты обработанных приборов;
- `events.jsonl` — журнал запросов, ответов и намерений записи;
- `plan.json` — снимок загруженных данных, SHA-256 Excel и список выбранных заданий;
- `run.json` — итоги и номера приборов, обработка которых не завершилась.

При аварийном завершении ОС окончательных CSV/JSON может не оказаться; сохранённые события остаются в `events.jsonl`. Перед повтором проверьте незавершённый прибор чтением.

Если EXE не открыл окно, сообщение запуска указывает журнал `%LOCALAPPDATA%\PulsarLoader\startup.log`. Передавайте для диагностики этот журнал или папку отчёта целиком.

## Проверка этой версии

Публичные тесты используют синтетические номера и показания. Проверяются импорт Excel, интерфейс, запись/чтение/остановка на имитаторе и форма ответа одиночного канала. Приватные захваты обмена и планы в комплект не включены. Состав Windows x64 и отсутствие консольной подсистемы EXE проверены статически. **Запуск комплекта на Windows и запись на настоящий счётчик ещё требуют проверки на вашем ноутбуке.**

Исходники и тесты находятся в `app`, код Windows-лаунчера и сборщика — в `source`. Переносимый комплект содержит официальный CPython 3.12.10, Tcl/Tk, openpyxl 3.1.5 и et_xmlfile 2.0.0. Источники и контрольные суммы дистрибутивов указаны в `runtime-provenance.json`, лицензии — в `licenses` и внутри `runtime`.
