ПУЛЬСАР — ЗАГРУЗКА ИЗ EXCEL 1.1.0

1. Распакуйте весь ZIP на Windows 10/11 x64.
2. Откройте PulsarLoader.exe двойным щелчком.
3. Нажмите «Открыть Excel…» и выберите свой XLSX.
4. Посмотрите «Проверка Excel», отметьте приборы в первой колонке.
5. Сначала «Прочитать выбранные» для одного прибора.
6. Затем «Записать выбранные…», проверьте список и подтвердите запись.

Python и библиотеки уже внутри. Команды вводить не нужно.
Папки app и runtime должны оставаться рядом с PulsarLoader.exe.

IP берётся из I, порт — из K, ХВС — из N, ГВС — из O.
Номера C и M сопоставляются между собой.
Веса обоих входов по умолчанию 0.01, их можно менять в окне.

Подробная инструкция — README.md.

Версия проверена локально на имитаторе; запуск на Windows и реальные
операции со счётчиком необходимо проверить на вашем ноутбуке.
