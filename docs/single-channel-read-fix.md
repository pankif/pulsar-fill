# Исправление чтения одиночного канала

Ранний вариант клиента ожидал маску канала в ответе команды `0x01`. Для «Пульсар теплосчетчик стандартный» ответ одиночного канала содержит только **4 байта Float32**, без маски. Маска остаётся в запросе чтения и в подтверждении записи командой `0x03`.

Неверное предположение было обнаружено при локальном анализе предоставленного журнала и сопоставлении с `PulsarM.GetParams` из драйвера TestAll. Исходный журнал, адрес подключения, номера и показания объекта в репозитории отсутствуют.

Исправление включено в CLI 1.0.1 и GUI 1.1.0. Проверки длины, адреса, функции, ID запроса и CRC сохранены. В публичной фикстуре `synthetic-read.json` отдельно сформированы выдуманные номер и значения; это синтетический эталон структуры пакетов, а не запись обмена с физическим прибором. Его проигрывает тест `test_replay_synthetic_single_channel_read`.

Чтение проверяется локальным имитатором и эталонными пакетами. Работа конкретного физического прибора и разрешение записи остаются отдельной аппаратной проверкой.
